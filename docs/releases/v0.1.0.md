# LumaShot v0.1.0 · First public release / 首个开源版本

LumaShot / 拾光截图 is a native macOS screenshot and annotation tool, now available under the MIT license.

## Download / 下载

Download **LumaShot-v0.1.0-macOS-universal-notarized.zip** from the assets below. The archive contains `LumaShot.app` for **Intel and Apple Silicon**, requires **macOS 14+**, and includes the MIT license. Extract it and move the app to Applications.

下载下方的 **LumaShot-v0.1.0-macOS-universal-notarized.zip**，解压并将 `LumaShot.app` 拖入「应用程序」。支持 Intel 和 Apple Silicon，要求 macOS 14 或更新版本。

The recommended archive is **Developer ID signed and Apple notarized**, with the ticket stapled to the app. Apple's notarization accepted both architectures with no reported issues, and the app passed local Gatekeeper assessment (`source=Notarized Developer ID`). This additional archive contains the same v0.1.0 application source; signing, notarization, and packaging have been added.

推荐公证包已完成 **Developer ID 正式签名、Apple 公证及票据装订**。双架构通过 Apple 检查，未报告问题，并通过本机 Gatekeeper 验证；应用功能源码仍为 v0.1.0，本次增加正式签名、公证和打包。

The original `LumaShot-v0.1.0-macOS-universal.zip` and `SHA256SUMS.txt` remain unchanged. That original archive is ad-hoc signed and not notarized. Choose the `*-notarized.zip` archive for installation.

原始压缩包及其校验文件保留不变，该旧包使用临时签名且未公证。安装时请选择名称带 `notarized` 的新包。

## Included / 功能

- Region, window, display, and scrolling screenshots / 区域、窗口、全屏、滚动长截图。
- Global Control + Shift + 1 / 2 / 3 / 4 shortcuts / 全局快捷键。
- Automatic scrolling with Accessibility approval and manual frame stitching / 自动滚动与手动拼接。
- Arrows, shapes, pen, text, numbered markers, mosaic, undo/redo / 常用标注、马赛克、撤销与重做。
- Native Retina output, clipboard copy, PNG/JPEG save / Retina 原图导出、复制、保存。
- Local history for the latest 100 original captures / 最近 100 张原始截图历史。

## Permissions and limitations / 权限与限制

Screen Recording approval is required for capture. Accessibility approval is only required for automatic scrolling; manual stitching is available without it. The current interface is in Simplified Chinese.

截图需要屏幕录制权限；自动滚动另需辅助功能权限，手动拼接无需辅助功能授权。当前界面为简体中文。

This is an early-stage release. Third-party automatic scrolling and physical multi-display arrangements still need broader real-world testing. Animated content, virtualized lists, repetitive patterns, or insufficient overlap can prevent stitching. Long captures are bounded by 50,000 pixels in height and approximately 80 megapixels total. History stores originals; export annotations before closing an editing session.

这是早期可用版本。第三方应用自动滚动和物理多显示器组合仍需更多实际验证。动画、虚拟列表、重复图案或重叠不足可能导致拼接失败。长图限制为 50,000 像素高、约 8,000 万总像素；历史记录保存原图，标注结果请复制或另存。

## Validation / 验证

The initial development validation passed 17 automated tests for stitching, annotation rendering, and storage; captured a real 2880 × 1800 Retina screen through ScreenCaptureKit; and verified native editor Copy/Undo routing and background selection-panel keyboard focus. See the linked CI workflow for repository checks. No claim is made that every third-party app or multi-display arrangement has been verified.

Verify the notarized archive using the accompanying `SHA256SUMS-notarized.txt`:

```sh
shasum -a 256 -c SHA256SUMS-notarized.txt
```

`SHA256SUMS.txt` continues to describe the original ad-hoc archive only.
